# Mukesh Raju Podilapu — Portfolio

Responsive multi-page portfolio built with HTML, custom CSS, vanilla JavaScript and Bootstrap 5.

## Pages
- `index.html` — Home and selected work
- `about.html` — Background, approach and toolkit
- `projects.html` — Detailed project case studies
- `experience.html` — Education, project experience and open-source contributions
- `contact.html` — Contact details and links

## Run locally
```bash
python -m http.server 8000
```
Open http://localhost:8000.

Bootstrap, Bootstrap Icons and Google Fonts load from CDNs, so an internet connection is needed for those assets.
