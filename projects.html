01 / DESKTOP SYSTEMS · PYTHON

Oryn — Workspace continuity

A desktop application focused on capturing a development workspace and restoring supported context later. The project explores how to map local application state, collect snapshots, synchronize metadata with a backend and rebuild a useful working environment.

Engineering areas: desktop GUI architecture, process and window inspection, filesystem mapping, API integration, authentication, snapshot numbering, payload handling and restore reliability.

Stack: Python, Qt, PyAutoGUI, FastAPI, PostgreSQL, Supabase.
