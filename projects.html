01 / DESKTOP SYSTEMS

Oryn · Cross-device workspace continuity

PERSONAL PROJECT

Oryn is a desktop application that captures supported development workspace state, stores snapshots in the cloud and helps reconstruct that context on another device. It focuses on the practical problem of returning to a development session without manually rebuilding every part of the environment.

What it does: captures workspace/project information, files and supported VS Code editor state, active file details and browser URLs. Snapshots are stored in Oryn Cloud and can be previewed and restored. It also includes snapshot history, comparison, retention controls and integrity checks for newly captured snapshots.

Engineering challenges: coordinating desktop GUI state with backend APIs, handling long-running capture operations, mapping paths across operating systems, keeping restore operations resilient when one adapter fails, and managing large snapshot payloads safely.

02 / AI & MACHINE LEARNING

ARC · AI engineering platform

PERSONAL PROJECT

ARC is an open-source AI engineering project built around learning machine learning, deep learning and modern AI systems by implementing concepts as reusable code rather than relying only on tutorial notebooks.

Work explored: foundational components such as dataset handling, a mean squared error loss and linear regression implemented from scratch. The larger direction is to grow a practical codebase for understanding the full AI engineering lifecycle.

Why it matters: implementing the building blocks exposes details that high-level libraries hide, from data flow and parameter updates to the structure of training code.

03 / SECURITY & PLATFORM ENGINEERING

NullBox · Capture the Flag platform

TEAM PROJECT · NULLCHAPTER

NullBox is a container-based CTF platform developed by NullChapter at VIT-AP. It is designed to host security challenges across areas such as web, pwn, reverse engineering and cryptography.

Platform capabilities: team management, challenge workflows, dynamic scoring and isolated on-demand challenge containers. The architecture uses a web application and backend data layer to coordinate users, teams and challenge instances.

Engineering focus: platform architecture, database-backed workflows, authentication, container orchestration and the boundary between application logic and isolated challenge environments.
