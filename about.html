I'm Mukesh Raju Podilapu, an Integrated M.Tech Computer Science student at VIT-AP University. I enjoy learning how software works by building it, debugging it and understanding the decisions underneath it.

01 / MY APPROACH

I prefer to
understand,
then abstract.

I’m interested in the mechanics behind the tools I use. When I work with an API, I want to understand the data model and failure modes. When I learn machine learning, I want to implement the algorithm and see what the math is doing in code.

That mindset has led me across backend development, desktop software, collaborative products, cloud infrastructure and machine-learning experiments.

I learn best by building. I prefer a small working implementation, real debugging and deliberate iteration over passively consuming long tutorials.

01 Understand the problem before choosing an abstraction.
02 Measure before guessing.
03 Treat failures as evidence, not dead ends.
04 Keep systems small enough to reason about.
