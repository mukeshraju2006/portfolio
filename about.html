I’m Mukesh Raju Podilapu, an Integrated M.Tech Computer Science student at VIT-AP University. I enjoy understanding systems deeply, building practical tools and learning by implementing ideas.

How I approach engineering

I prefer to understand the problem before reaching for a framework. That means tracing how data moves, identifying failure cases, reading documentation and testing assumptions. I enjoy debugging because it turns vague symptoms into concrete engineering questions.

What I’m focused on

My primary direction is AI/ML engineering. I’m building foundations across classical machine learning, deep learning and the systems needed to deploy and operate models reliably. Backend engineering, databases, Linux and infrastructure remain important parts of that picture.

Current toolkit

  • Languages: Python, Java, JavaScript, TypeScript and SQL
  • ML and data: NumPy, Pandas, scikit-learn and machine-learning fundamentals
  • Backend: FastAPI, PostgreSQL, SQLAlchemy and REST APIs
  • Tools: Git, Docker, Linux, Vercel and Supabase

Outside the editor

I value clear technical communication, thoughtful collaboration and open-source work. I learn best by building something, testing it, finding what breaks and improving it.
